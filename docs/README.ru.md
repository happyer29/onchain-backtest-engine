# On-Chain Backtest Engine

**Язык:** [English](../README.md) · Русский · [简体中文](README.zh-CN.md)

Локальный движок для исследования ончейн-данных и воспроизводимого бэктестинга
на одном компьютере. Он ограниченно читает внешний источник, сохраняет
проверенные неизменяемые артефакты и выполняет стратегии без SQL и сети в
основном цикле. Это альфа-версия исследовательского ПО, не система для реальной
торговли и не финансовая рекомендация.

## Инструменты

| Область | Возможности |
| --- | --- |
| Подготовка данных | Проверка источника, планирование диапазона и сохранение снимков Parquet. |
| Стратегии | Эталонный движок, Sniping, Copy Buy и FirstSwap с явными контрактами исполнения. |
| Ончейн-исследование | Активность подписывающих кошельков и совместные покупки по проверенным локальным артефактам. |
| ML-инфраструктура | Причинно доступные признаки, метки, выборки и существующий безопасный путь точной модели. |
| Операции | Очередь заданий, проверка и происхождение артефактов, результаты, закрепление, сборка мусора и резервные копии. |
| Интерфейсы | Типизированный CLI, локальный Control API и React-интерфейс с общими контрактами. |

Отдельный [базовый ML-пример](ml-baseline.ru.md) использует только синтетические
данные, одну логистическую модель и четыре простых признака. Он не является
торговой стратегией или доказательством качества прогноза.
Точную модель можно обучить на ранних строках того же ReplayPack и применить
к поздним: при создании PredictionSet выберите «Без прогноза до первой модели»,
а в запуске FirstSwap — то же правило инференса. Ранние строки останутся без
прогноза; пробелы расписания после первой модели по-прежнему вызывают ошибку.

Для демонстрации есть [обзор проекта (99 с)](assets/project-overview-demo-ru.mp4)
и отдельный [ролик про ML-проход (67 с)](assets/ml-workflow-demo-ru.mp4),
оба с русской озвучкой. В них использованы синтетические данные; подключение
реального источника и полный UI-запуск ML-задачи не записаны.

## Быстрый старт

Нужны Python 3.13 и [`uv`](https://docs.astral.sh/uv/). Linux x86_64 и macOS
arm64 поддерживаются напрямую; в Windows 11 x86_64 используйте WSL2 и Ubuntu.

```bash
uv sync --all-groups --frozen
source .venv/bin/activate
backtest --help
cp configs/local-16gb.toml configs/local.toml
backtest serve --config configs/local.toml
```

Перед подключением реального источника настройте каталог данных, возможности
источника и секреты. Не сохраняйте учётные данные в Git. Интерфейс доступен на
настроенном порту `127.0.0.1`. Подробности — в [руководстве по началу работы](getting-started.ru.md)
и [конфигурации](configuration.ru.md).

Офлайн-пример ML запускается без источника:

```bash
python -m backtest.examples.ml_baseline
```

Команда выводит размеры обучающей и тестовой выборок, отдельно учитывает
неизвестные и исключённые по времени метки, а также базовые метрики. Признаки
строятся только по предшествующим синтетическим событиям.

## Основной процесс

```text
inspect-source → plan-dataset → prepare-dataset → compile-replay (необязательно)
               → resolve-run → run / sweep → просмотр и проверка результатов
```

`backtest research` выполняет ограниченное исследование кошельков, а
`backtest serve` открывает локальный интерфейс. Актуальный синтаксис показывает
`backtest <команда> --help`; см. также [справочник CLI](cli-reference.ru.md).

Полнота источника и своевременная доставка данных не предполагаются.
Неподдерживаемые, устаревшие, повреждённые или слишком большие входы явно
отклоняются. Результат исследования автоматически не допускается к исполнению;
синтетический расчёт помечается отдельно. Точные ограничения описаны в
[архитектуре](architecture-deep-dive.ru.md).
