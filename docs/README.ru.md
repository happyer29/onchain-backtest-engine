## Архитектура и участие в проекте

[Подробная архитектура](architecture-deep-dive.ru.md) переводит единственный
нормативный источник целевой архитектуры. [Обзор](architecture.ru.md) кратко
излагает его без самостоятельных решений. Перед изменениями прочитайте
затрагиваемые разделы и [руководство по участию](../CONTRIBUTING.ru.md).

Раздел 3.4 подробной архитектуры описывает реализованные возможности.
Наличие порта или записи в каталоге не означает доступность целевого
расширения. Неподдерживаемая семантика приводит к типизированной ошибке.

Допуск внешнего источника к replay требует сгенерированного доказательства для
конкретного диапазона и отображения полей. Проверка на тестовых данных не
доказывает полноту или достоверность внешнего источника. Результаты замеров
относятся только к проверенным входным данным, режиму исполнения, оборудованию
и физическим настройкам.
Исследовательские снимки сохраняют `UNKNOWN` source fidelity и не заменяют
этот допуск к исполнению.

Английские файлы без языкового суффикса являются каноническими. При
расхождении перевода с английским текстом применяется английская версия.
