# Офлайн-пример ML

**Язык:** [English](ml-baseline.md) · Русский · [简体中文](ml-baseline.zh-CN.md)

После установки проекта запустите:

```bash
python -m backtest.examples.ml_baseline
```

Пример самостоятельно создаёт почасовые синтетические наблюдения: он не читает
внешний источник, артефакты, секреты или локальные данные пользователя. Одна
модель логистической регрессии использует ровно четыре признака: число событий,
их среднее значение и долю ошибок за предшествующие шесть часов, а также
текущий час UTC. Вектор рассчитывается до генерации исхода этого часа.

Первые 70% наблюдений образуют кандидатную обучающую часть. Неизвестные метки
учитываются отдельно. Метки, которые стали бы известны лишь после начала
тестового периода, исключаются. Нормализация обучается только на обучающих
строках. На оставшихся строках с известными метками рассчитываются Accuracy,
Brier score и Log loss. Фиксированный seed делает запуск воспроизводимым.

Числа служат учебной проверкой на сгенерированных данных, а не измерением
ончейн-рынка или доказательством доходности. Модель не сохраняется и не
допускается к исполнению стратегий.
