# 离线 ML 基础示例

**语言：** [English](ml-baseline.md) · [Русский](ml-baseline.ru.md) · 简体中文

安装项目后运行：

```bash
python -m backtest.examples.ml_baseline
```

示例自行生成按小时排列的合成观测，不读取外部数据源、工件、凭据或用户数据。
它只训练一种逻辑回归模型，使用四个特征：过去六小时的事件数量、平均事件值、
错误比例，以及当前的 UTC 小时。每小时的特征都在该小时的合成结果生成前
计算。

前 70% 的观测作为候选训练期；未知标签单独计数。若训练标签在测试期开始时
仍不可得，就将它从训练集中排除，避免时间泄漏。特征标准化仅在训练集上
拟合。剩余的已知标签构成固定留出集；命令输出准确率、Brier 分数、对数
损失和各类样本计数。固定随机种子使结果可复现。

这些指标只用于演示，不是链上实测数据或交易表现证据。模型不会保存、注册
为生产模型或接入策略引擎。
