# Журнал изменений

Здесь перечислены заметные для пользователя изменения. Формат следует
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Детерминированное локальное воспроизведение проверенных неизменяемых Parquet
  snapshots с необязательным ускорением через ReplayPack.
- Pump.fun Sniping со строгим допуском по source evidence и отдельными режимами
  `EXOGENOUS_REPLAY` и `EXOGENOUS_VIRTUAL_SETTLEMENT`.
- Типизированные CLI и same-origin Web UI поверх надёжной очереди задач с
  изолированными дочерними процессами, отменой, повтором и восстановлением
  после перезапуска.
- Профили Linux x86_64, macOS arm64 и Windows 11 через WSL2/Ubuntu.
- Документация продукта на английском и русском языках.
- Проверки установленного пакета: CLI, loopback API и статические ресурсы UI;
  quality gates CI для Linux x86_64 и macOS arm64.

### Изменено

- Детерминированная пагинация запусков от новых к старым использует
  восстанавливаемый индекс каталога, связанный с манифестами, и проверяет
  каждый выбранный артефакт.
- Таблицы задач и запусков и Sniping dashboard хранят одну ограниченную
  страницу; сортировка и поиск работают внутри страницы, polling адаптируется
  к состоянию, а сводка и страница результатов запрашиваются вместе.
- Повторное чтение артефактов использует ограниченные свидетельства проверки,
  защищённые физическим fingerprint; источником истины остаются опубликованные
  байты в файловой системе.
- Чистый перезапуск может использовать проверенный receipt каталога; сбой,
  изменение набора артефактов или повреждение требуют полной проверки.

### Исправлено

- Сохранён прежний JSON envelope команды CLI `jobs`, тогда как HTTP response
  содержит курсор пагинации.
- Некорректные Solana genesis identities и разделители endpoint или credentials
  отклоняются до попадания source-конфигурации в идентичность артефактов.
  Полные base58 references сохраняют исходные байты; проверки смешанных сетей
  остаются активными.
