# Support

## Need help getting started?

Check these resources first:

1. [Getting started](docs/getting-started.md).
2. [Configuration](docs/configuration.md).
3. [CLI reference](docs/cli-reference.md).
4. [Honest limitations](README.md#honest-limitations).

If you cannot find an answer, open an issue using the appropriate template and
include a minimal reproduction, your Python version, operating system, and a
safe excerpt of the error. Before publishing, remove credentials, endpoints,
absolute paths, personal or trading wallet addresses, and sensitive artifact
IDs.

Do not report security issues publicly. Follow [SECURITY.md](SECURITY.md)
instead.

## Support the project

- Star the repository.
- Tell people who care about reproducible on-chain research about the project.
- Contribute documentation, a test, or a small bounded fix.
- Help verify the project on another supported host.
